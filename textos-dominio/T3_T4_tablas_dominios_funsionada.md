# T3 + T4 — Value Stream Map + Use Case Priority Board (Fusión) — Tabla de personalización por dominio
 
**Nota de alcance:** Este documento fusiona los textos de T3 (Mapa de Procesos / Value Stream Map) y T4 (Tablero de Priorización / Use Case Priority Board) en una única tabla maestro de 719 entradas de texto único. Está organizado primero por secciones compartidas (constants.ts de ambos), luego por componentes de T3, y finalmente por componentes exclusivos de T4.
 
**Pauta de generalización aplicada:** La columna "Generalización (Gobierno de Proyectos e Iniciativas)" sustituye referencias específicas de dominio (IA, datos, transformación digital) por lenguaje agnóstico de iniciativa. Ejemplo: "Riesgo IA" → "Riesgo regulatorio/operativo"; "Caso(s) de uso" → "Iniciativa(s)"; frameworks concretos (AI Act, RGPD, DORA, NIS2, GDPR, ISO 27001, COBIT 2019, ITIL4) → "el marco normativo/contractual aplicable" o "los estándares de gestión aplicables".
 
**Estructura del archivo:**
- A. CONSTANTS (T3 + T4 compartidos): PHASE_CONFIG, DIMENSION_CONFIG, AI_CATEGORY, benchmarks, etc. (~140 entradas)
- B. COMPONENTES T3: T3View (80), ProcessInterviewModal (75), StagesTab (130), T3 constants.ts (60), store.ts (40), contextBuilder (4) = 386 entradas totales
- C. COMPONENTES T4 / FUSIÓN: ImportFromT3Modal (~193 entradas)
- D. FLAGS DE AMBIGÜEDAD: Textos que requieren clarificación del usuario
